# Core Python

A collection of small Python practice scripts covering core language fundamentals: loops, string manipulation, recursion, arithmetic, pattern printing, basic OOP (`Person`, `Shape`/`Circle`/`Rectangle`/`Triangle` with tests), and simple concurrency (`RaceCondition`, `NoRaceCondition`).

These are individual learning exercises rather than a single application — each `.py` file is self-contained and runnable on its own, e.g.:

```bash
python Core/Factorial.py
```

## Contents

- **Language basics:** `Loop.py`, `AllArithmetic.py`, `Concatenate2Str.py`, `CountStrChar.py`, `ExractStr.py`, `NevenNodd.py`
- **Classic algorithms:** `Factorial.py`, `fibbonacci.py`, `palindrome.py`, `reverse.py`, `Prime.py`, `Armstrong.py`, `sqrt.py`, `Divby7.py`
- **Patterns:** `Pattern1.py`, `Patern2.py`
- **OOP practice:** `Person.py` + `TestPerson.py`, `Shape/` (`Shape`, `Circle`, `Rectangle`, `Triangle` + `TestShape.py`)
- **Concurrency:** `RaceCondition.py`, `NoRaceCondition.py`
- **Misc:** `AgeCalculater.py`, `5RandomNo.py`, `Maxof2no.py`, `Smaller0f2no.py`, `StartEndDate.py`, `1YearMaintenance.py`, `FaultyCalculator.py`
